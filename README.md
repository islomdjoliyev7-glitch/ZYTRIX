# ZYTRIX

Terminal uchun tizim monitoring dasturi: CPU, RAM, batareya, internet,
top jarayonlar va jonli dashboard.

## O'rnatish

```bash
git clone https://github.com/USERNAME/zytrix.git
cd zytrix
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

## Imkoniyatlar
- Kompyuter haqida ma'lumot (harorat, uptime)
- RAM, CPU (har bir yadro), batareya monitoring
- Internet tezligi
- Eng ko'p RAM yeyayotgan jarayonlar
- Live dashboard (Ctrl + C bilan chiqish)
